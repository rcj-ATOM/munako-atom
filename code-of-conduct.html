Code of Conduct（行動規範）

Munako ATOM は、公正・安全かつオープンな技術開発と競技参加を心掛けます。

1. フェアプレーとリスペクト

他チーム、審判、運営スタッフ、および観客に対して常に敬意を払い、スポーツマンシップに則った行動をとります。

2. オープンソースと学び合い

自らの技術や知識を共有し、コミュニティ全体の技術向上に貢献します。他者の成果を尊重し、剽窃（無断盗用）は行いません。

3. 健全な競技環境の維持

会場内でのルール遵守を徹底し、全員が快適かつ安全に競技・技術交流を行える環境づくりに努めます。
